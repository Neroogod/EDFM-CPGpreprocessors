    Stage 7 Export deck

    The fracture stages are not undone; this just writes the deck from an earlier point.

    No fluid model, rock–fluid tables or schedule are written. The dataset carries the grid and nothing else, ready to open in Builder and populate there.

    The deck stops at the end of GRID. PROPS, SOLUTION, SUMMARY and SCHEDULE are yours to add — nothing is invented. Units are METRIC.

      What runs where

      Building fracture cells means intersecting fracture planes with grid cells, computing contact areas and connectivity indices. That is several thousand lines of MATLAB in MRST, and there is no browser port of it. Everything downstream — block addressing, unit conversion and writing the deck — is arithmetic and text, so it runs here.

      For the full EDFM / pEDFM / CPEDFM pipeline, run this same page against your own MATLAB and MRST installation: python web/server/serve.py. An engine picker then appears at the top and the fracture stages unlock — same page, same deck, with MRST doing the geometry.

      One difference to know about. This page takes the active-block set straight from ACTNUM. MRST's processGRDECL can deactivate more than that — it discards disconnected components and degenerate cells — so for grids where those matter, the block count here will differ from the MATLAB export.

      Generated decks contain only data derived from your file. Nothing is uploaded — all processing happens in this browser.
